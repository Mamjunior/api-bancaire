Effectuer un dépôt
Ajouter des fonds sur un compte existant
POST /comptes/{id}/depot
💰
Paramètres du dépôt
Solde actuel
—
ℹ️
Comment ça fonctionne

Un dépôt ajoute le montant spécifié au solde actuel du compte sélectionné.

✓ Le montant doit être strictement positif
✓ Le compte doit exister dans le système
✓ Le nouveau solde est retourné immédiatement
REQUÊTE EXEMPLE
POST /comptes/1/depot
{
  "montant": 50000
}
Effectuer un retrait
Retirer des fonds d'un compte existant
POST /comptes/{id}/retrait
💸
Paramètres du retrait
Solde disponible
—
ℹ️
Comment ça fonctionne

Un retrait déduit le montant du solde actuel. L'opération est refusée si le solde est insuffisant.

✓ Le montant doit être positif
✗ Refusé si solde insuffisant
✓ Le solde restant est retourné
REQUÊTE EXEMPLE
POST /comptes/1/retrait
{
  "montant": 20000
}
